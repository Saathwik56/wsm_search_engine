1. Executive Summary

This project implements a complete, self-contained Information Retrieval (IR) system designed for the Web Search and Mining (WSM) curriculum. The search engine features strict modular separation across all seven classical IR stages: document ingestion, tokenization, text normalization, positional inverted index construction, query processing, wildcard processing, and frontend graphical user interface.

The system is built entirely using standard Python without external third-party dependencies (such as NLTK, NumPy, or Lucene), guaranteeing seamless portability and direct execution on standard environments.

Key Architectural Highlights
  • Pure Standard Library: Employs dataclasses, re, unicodedata, json, math, and tkinter.
  • Dual Wildcard Resolution: Implements both a Permuterm Index (rotations with binary search prefix lookup) and a K-gram Index (trigram postings with regex post-filtering).
  • Full Boolean Parsing: Uses Dijkstra's Shunting-yard algorithm to convert infix expressions into Reverse Polish Notation (RPN), supporting AND, OR, NOT, nested parentheses, and implicit AND conjunctions.
  • Positional Inverted Index: Retains exact word positions for phrase queries (e.g., "inverted index") and character offsets for live snippet highlighting.
  • Tkinter GUI: Features a search input box with <Return> trigger, a distinct Search button, and a read-only scrolled result area with highlighted matches and wildcard diagnostics.

3. Detailed Module Specifications

Module 1: Document Loader (src/document_loader.py)

The Document Loader is responsible for discovering, reading, and structuring document data from disk or in-memory sources.

  • Document Data Model: Represents documents via the Document dataclass, storing doc_id (integer), title, absolute path, raw content, and metadata. Provides dynamic properties for word_count and char_count.
  • Encoding Resilience: Automatically detects and gracefully handles encoding variants (utf-8, utf-8-sig, latin-1, cp1252) with byte replacement fallback to avoid file reading aborts.
  • Directory Ingestion: Ingests all text files with extensions .txt, .md, .data deterministically sorted for reproducible document identifier assignment.

Module 2: Tokenizer (src/tokenizer.py)

Transforms raw character streams into structured token streams while preserving critical spatial metadata:

  • Token Representation: Encapsulates tokens inside a Token dataclass containing:
    • text: Normalized lexical string.
    • position: Zero-indexed word index in the document ($0, 1, 2, \dots$) essential for positional index construction.
    • start_char & end_char: Character offsets in the raw document string enabling snippet extraction and exact substring highlighting.
  • Query-Aware Tokenization: Implements distinct patterns for document indexing (alphanumeric words and contractions) versus query parsing (which preserves wildcard characters * and ?).

Module 3: Text Normalizer & Case Folding (src/normalizer.py)

Standardizes vocabulary across documents and queries to eliminate superficial lexical divergence:

  • Case Folding: Converts all characters to lowercase form to support case-insensitive retrieval.
  • Diacritic & Accent Stripping: Decomposes Unicode characters via NFKD normalization and eliminates non-spacing mark bytes (e.g. café becomes cafe).
  • Punctuation Stripping: Cleans leading/trailing non-alphanumeric punctuation while maintaining valid intra-token characters.
  • Stopword Filtering: Configurable filtering of 120+ standard English stopwords (e.g. the, is, at, which).
  • Porter Stemming: Self-contained implementation of Martin Porter's 1980 suffix-stripping algorithm (Steps 1a, 1b, 1c, 2, 3, 4, 5a, 5b) allowing grammatical grouping (e.g., retrieval, retrieving, retrieves $\rightarrow$ retriev).

Module 4: Inverted Index Construction (src/inverted_index.py)

Constructs a Positional Inverted Index mapping vocabulary terms to sorted postings records:

  • Posting Structure: Each Posting stores doc_id, term_frequency ($tf$), and the sorted array of word positions: 
    Posting(doc_id=1, term_frequency=3, positions=[5, 23, 78])
  • Index Organization: Postings lists are guaranteed sorted by doc_id ascending, allowing linear-time intersection ($O(M+N)$) during query processing.
  • Persistence: Provides built-in save_to_file(path) and load_from_file(path) to serialize and deserialize the entire inverted index to and from JSON format.

Module 5: Query Processing (src/query_processor.py)

The core engine supporting Boolean, Phrase, Ranked Free-Text, and Wildcard search modalities:

  • Boolean Retrieval (Shunting-Yard Algorithm): Parses boolean queries (with operators AND, OR, NOT and parentheses) by converting infix expressions to Reverse Polish Notation (RPN). Automatically inserts implicit AND conjunctions between consecutive operands or between operands and NOT (e.g. index NOT permuterm $\rightarrow$ index AND NOT permuterm).
  • Positional Phrase Retrieval: Evaluates exact word sequences (e.g. "inverted index"). The algorithm identifies candidate documents containing all query terms, extracts their position arrays, and verifies whether an unbroken chain of consecutive positions ($pos_{k+1} = pos_k + 1$) exists.
  • Ranked Free-Text Search (TF-IDF): Computes logarithmic Term Frequency - Inverse Document Frequency with document length normalization: 
    Score(D, Q) = sum( (1 + ln(TF_t,D)) * ln(1 + (N / DF_t)) ) / sqrt(Length_D)
  • Contextual Snippet Generation: Computes a localized context window centered around matching terms, snaps boundaries to whole words, and tags matching terms for highlighting.

Module 6: Wildcard Processing (src/wildcard_processor.py)

Implements the two fundamental wildcard indexing strategies from classical IR literature:

Technique Data Structure Transformation / Query Mechanism Complexity / Advantage
Permuterm Index Dictionary of cyclic rotations + sorted prefix array Appends boundary $ to term. Rotates query until * is at the right edge:
• X* $\rightarrow$ $X* (lookup prefix $X)
• *X $\rightarrow$ X$* (lookup prefix X$)
• X*Y $\rightarrow$ Y$X* (lookup prefix Y$X) 		Binary search prefix range lookup $O(\log V)$. Highly efficient for single wildcard queries.
K-gram Index Inverted index of character 3-grams to vocabulary terms Pads words with $term$. Segments wildcard query into 3-grams, intersects postings lists of candidate terms, and eliminates false positives with regex post-filtering. Handles multiple arbitrary wildcards (e.g. p*rm*t*rm) where rotations are ambiguous.

Module 7: Frontend GUI (src/gui.py)

Provides a modern desktop interface developed using Python's native tkinter and ttk:

  • Search Input Box: Sizable text entry with automatic focus, Enter key binding (<Return>), and a clear button.
  • Search Button: Primary styled accent button (🔍 Search) providing immediate search execution.
  • Read-Only Result Area: Scrolled text box maintaining state="disabled" so users cannot edit results, while allowing full text selection and copying. Utilizes rich Tkinter tags for document headers, metadata badges, scores, wildcard expansions, and highlighted snippet terms.
  • Corpus & Index Management: Directory browsing, index rebuild trigger, and index status metrics.
  • Pre-processing Toggles: Live checkboxes to enable or disable Porter Stemming and Stopword Removal.
